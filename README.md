# Anahata Retreat

The official website experience for Anahata Retreat, a beachfront resort on Ashwem Beach in North Goa.

## Development

```bash
npm install
npm run dev
```

## Production checks

```bash
npm run lint
npm run build
```

The website is a React single-page application built with Vite. Resort imagery is stored in `public/images` and the primary content is maintained in `src/App.jsx`.
